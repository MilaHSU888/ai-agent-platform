# Phase 1 UAT 與需求追蹤

2026/10/08 依 [PRD v0.18](../PRD.md) 同步。首個試點為「採購報價單彙整工具」；本次僅更新需求及測試規格，所有正式 UAT 仍待執行，不因文件同步而宣告通過。歷史 Demo 證據僅供追溯。

## 1. UAT 通過規則

- 每個正式需求 ID 必須對應測試證據或經核准的不適用理由。
- 越權、違反管理者模型設定而呼叫雲端、AI 原始值被覆寫、未確認即可匯出為阻斷缺陷。
- 其他缺陷分級、允許未關閉數量及驗收緩衝期由 `TBD-UAT-001` 決定。
- Demo 畫面或口頭展示不能取代正式環境證據。

## 2. 核心 UAT 情境

本表「納入清單／核准工具」指選定的 1–2 個試點與另有專項要求的功能，不表示既有盤點全部由專案團隊代上架。技術移轉後由客戶自行上架其餘工具；新工具演練可由客戶操作，不增加專案團隊代建工具數量。

| Case | 角色／情境 | 對應需求 | 預期結果 |
|---|---|---|---|
| UAT-001 | 一般使用者正常登入 | P1-AUTH-001～003 | 成功登入，只看到獲授權工具 |
| UAT-002 | 無權限使用者嘗試直接開啟工具 | P1-AUTH-003、006；P1-PORTAL-005 | 前後端均拒絕並記錄事件 |

| UAT-005 | 從 WorkHub 逐項啟動納入清單的既有 LLM 工具 | P1-TOOL-002、003、005、007；P1-LLM-001～003 | 入口與權限正確，且已確認使用 LLM 的請求依正式架構經 LLM Proxy |

| UAT-014 | 模型或匯出失敗後重試 | P1-VIS-012 | 無半完成檔案，狀態與錯誤可追溯 |

| UAT-016 | 留存到期與未授權查閱 | P1-VIS-014；P1-LLM-006 | 依政策刪除或拒絕，且留有稽核證據 |
| UAT-017 | 從 WorkHub 啟動 OpenWebUI | P1-TOOL-006；P1-PORTAL-004、005 | 有權限者導向設定 URL；無權限、停用或失效時被阻擋或收到明確提示 |
| UAT-018 | 地端 5090 辨識與成功率量測 | P1-VIS-003、015 | 核准測試集由地端 RTX 5090 執行，保留硬體、版本、設定、原始結果與可複核報告，不連未核准雲端；未達門檻依 PRD 1.3 另議 |
| UAT-019 | 品保校對效率與滿意度 | PRD 1.2；TBD-KPI-001 | 效率目標待核准，不沿用 50%；有效問卷滿意／非常滿意高於 80%。逾期排除須符合第 7 章條件及書面通知，不於本次啟用 |
| UAT-020 | 使用者從書籤、直接 URL 或其他外部入口進入工具 | P1-OBS-001 | 不產生 WorkHub 有效入口點擊，不納入入口點擊統計與主管分析；模型呼叫仍依 Proxy 規格記錄 |

> **OpenWebUI 待決策影響**：共用／分部門 URL、試點占額與時數仍待確認，不沿用固定加一週承諾。分部門方案如核准，補充部門對應、跨部門拒絕、未設定 URL 及異動案例；逾期共用 URL 方案须書面通知才啟用。
