# Phase 1 工具與權限盤點

## 工具盤點表

本表依 `UMT小工具功能分類整理表.md` 保存現有工具盤點，首個試點已選定「採購報價單彙整工具」，其他工具供第 2 個試點評估及客戶後續上架使用，不是平台允許清單或本次逐項代上架承諾。符合平台接入規範的其他工具亦可上架。

試點需完成容器、SSO、Gateway／事件等必要接入，保留原業務功能。技術移轉後由客戶 AI 團隊自行上架其他工具。AI 識圖獨立建置且不占試點名額；OpenWebUI 入口另有專項要求，是否占額仍待決策。

下列 LLM 分類為盤點當下現況，不限制後續路由；使用 LLM 的工具可由後台切換相容且符合資料政策的核准地端／雲端模型。AI 識圖仍依核准規格使用地端 5090。

### LLM 分類摘要

## 待確認清單

- AD／SSO 協定、Tenant／Domain、Claim 與群組同步頻率。
- 一人多部門、代理主管、調職、留停及離職規則。
- 主管查看範圍是直屬部門、管理階層或指定群組。
- IT 與資安是否使用不同管理角色。
- 工具端採共用 SSO、一次性 Token 或既有登入的方式。
- 優先收齊選定試點的正式／測試 URL、Owner、健康檢查、維護窗口、支援窗口及停用方式；其餘由客戶上架前補齊。
- 採購報價單彙整工具的 AI 元件是否實際使用 LLM，以及是否須套用 LLM Proxy 規則。
- OpenWebUI 與 CNC 排程使用的雲端模型、資料分級、核准端點及 Proxy 路徑。
- CNC 作業指導書翻譯、地端 n8n 平台及 AI 識圖的地端模型、推論端點與維運責任。
- 地端 n8n 平台中哪些工作流納入 WorkHub、哪些工作流實際使用 LLM。
