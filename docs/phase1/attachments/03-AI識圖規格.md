# Phase 1 AI 識圖規格

2026/10/08 依 [PRD v0.18](../PRD.md) 恢復獨立完整建置、地端 RTX 5090、人工整體確認及 Excel 匯出之需求基準，不占試點名額。2026/09/11 前端交接僅為歷史實作，正式功能與 UAT 尚未完成。

## 1. 目的與範圍

AI 識圖協助品檢員從工程圖取得檢點與規格資料，降低人工整理時間。AI 識圖模型於地端 NVIDIA RTX 5090 運算環境執行；AI 只提供辨識建議，最終結果仍由品檢員人工覆核確認。

本附件定義產品行為與待確認事項，不將個別 PDF、Excel 或模型測試結果直接視為正式產品需求或驗收標準。

## 2. 使用流程

1. 使用者上傳工程圖。
2. 系統檢查檔案是否合法並建立識圖工作。
3. 系統於地端 NVIDIA RTX 5090 環境進行辨識，產生檢點、規格及圖面位置。
4. 使用者透過圖面縮放及定位逐項核對。
5. 使用者只修正錯誤或需調整的項目，不需逐筆點選正確。
6. 使用者完成整體最終確認。
7. 系統依客戶核准格式匯出 Excel。
8. 系統保存 AI 原始值、人工修正值及必要稽核紀錄。

## 3. 工作狀態

```text
uploaded → validating → processing → review_required → confirmed → exported
               ↘ rejected       ↘ failed        ↘ failed
```

- `rejected`：檔案格式、大小、頁數、加密或損壞不符合規則。
- `failed`：辨識、資料保存或匯出失敗；需提供可理解的錯誤與安全重試方式。
- `review_required`：AI 結果已產生，等待人工覆核。
- `confirmed`：使用者完成整體最終確認。
- `exported`：依核准格式成功產生 Excel。

確認後若修改結果，系統須建立可追溯的後續版本或要求重新確認，不得悄悄改變已確認資料。

## 4. 辨識項目資料

每個辨識項目至少應能表達：

- 所屬工作、頁面與檢點／球標。
- 圖面上的位置。
- 品保核准的辨識欄位與 AI 原始值。
- 人工最終值、修正者與修正時間。
- 匯出版本與必要稽核關聯。

正式辨識欄位、資料型別、必填與判定規則由品保確認後定義。

## 5. 前端行為

- 支援工程圖頁面切換、放大、縮小及平移。
- 點選結果時，圖面移至對應區域並清楚標示位置。
- 右側只顯示一組目前結果，不並列 AI 與人工兩組值。
- 使用者可在圖面附近或結果區直接修正錯誤。
- 不要求逐筆確認正確，但匯出前必須完成整體最終確認。
- 不得只使用顏色表示錯誤、警告或確認狀態。

## 6. Excel 匯出

- 依品保核准的正式格式與範本版本匯出。
- 正式欄位、格式、判定、簽核及其他必要行為由品保確認。
- 若必要資料缺失、範本版本不符或匯出失敗，不得提供看似成功的不完整檔案。
- 匯出檔須能追溯來源工作及確認版本。

## 7. 準確率與驗收

依 PRD 1.3 與 P1-VIS-015，核准門檻前不承諾準確率；本條驗收量測與報告完整性及可複核性。首次未達核准門檻時由雙方另議調整方案，依現行時數合約計算投入。P1-VIS-013 為人工修正率，公式須客戶確認。

本節定義模型測試與驗收所需量測，不代表這些數值屬於 Phase 1 產品成功指標。AI 識圖項目正確率可在測試／驗收資料中標示核准目標與實測結果；若未來要作為持續性產品成功指標，須另案評估資料標註、測試、報表與維運成本。

正式驗收前需由品保提供或核准：

- 代表性工程圖與標準答案。
- 測試資料的廠區、料號及圖面類型範圍。
- 項目是否找到、各欄位是否正確的比對方式。
- 準確率、人工修正率及處理時間的計算方式。
- 可接受門檻及必須阻擋上線的錯誤類型。

成功率測試須在預定的地端 NVIDIA RTX 5090 環境執行，並保存硬體資訊、模型版本、推論設定、測試資料集版本、樣本數、AI 原始結果、失敗案例與測試時間。首次測試與調整後複測應使用相同版本的核准測試集，確保結果可重現及比較。

個別樣本或既有模型測試結果只作後續技術分析材料，不直接成為 PRD 驗收門檻。

## 8. 待確認事項

- 支援檔案格式、大小及頁數上限。
- 正式辨識欄位與判定規則。
- 地端 5090 測試所用模型版本、推論設定、系統串接方式及維運 Owner。
- Excel 正式格式、欄位及簽核要求。
- 基隆、汐止及越南廠區的使用者、語言、網路與流程差異（TBD-NFR-004）；跨境傳輸、加密、落地與法遵依 TBD-VIS-003，未確認前不得進行越南實機接入。
- 原圖、辨識結果、修正結果、匯出檔及稽核資料的保存期限。
