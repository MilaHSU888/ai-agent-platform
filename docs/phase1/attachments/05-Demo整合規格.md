# 更新版 Demo 整合規格

日期：2026/10/08。基準：PRD v0.18、DEC-017。來源是客戶 UMT Demo，不是另一份已簽核 PRD。

## 使用方式

在原平台 http://localhost:3002/ 操作；新增六個管理入口並保留工具中心、使用分析及既有工作區。依使用者 2026/10/08 指示移除頂部 Demo 說明橫幅；各模擬操作仍保留必要提示。資料保存在同一瀏覽器 localStorage；跨瀏覽器不共享。勿輸入敏感資料，附件只保存檔名。

## 互動與驗證

| 項目 | 預期行為 | 需求追蹤 |
|---|---|---|
| 開發者提交 | 名稱、描述、部門、AI／非 AI、程式／image 檔名、Owner、CPU、記憶體、GPU、網路、入口、模型及範圍分步輸入；勾選示範確認才可提交 | DEMO-002 |
| 發布 | 提交進驗證中；模擬檢查與測試皆完成才送核准；核准後目錄可使用；退回清除檢查狀態 | DEMO-002 |
| 更新回復 | 保留前版，更新重走檢查；回復後先維護，再人工恢復；不操作真實容器及資料庫 | DEMO-002/003 |
| 入口一致性 | 維護、下架、待核准與未授權皆阻擋；新增工具按其部門出現在目錄；設定說明與 URL 即時連動 | DEMO-003 |
| 分類／收藏 | 新增、重新命名及刪除空分類，拖曳或下拉移動工具，首頁功能分類篩選；手動收藏與點擊分開 | DEMO-001 |
| 聯絡與授權 | 平台或工具問題可提交，顯示唯一示範編號、狀態及回覆；申請工具可由管理者在 Demo 核准 | DEMO-004 |
| 模型 | 管理顯示名稱；地端限定拒絕雲端；AI 識圖不能解除地端限定；非 AI 不提供模型設定 | DEMO-005 |
| 紀錄 | 示範入口點擊與管理操作分開，操作可下載；未發送真實通知 | DEMO-003 |

- 兩頁分工瀏覽器驗證通過：開發者提交更新／檢查／測試／送審 → 發布管理核准；部門篩選、右側詳情切換及關閉皆通過。已修正抽屜被頂部導覽遮擋的層級問題，並檢視兩頁截圖。正式 UAT 狀態不變。
