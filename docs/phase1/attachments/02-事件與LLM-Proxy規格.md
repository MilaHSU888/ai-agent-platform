# Phase 1 使用事件與 LLM Proxy 規格

2026/10/08 依 [PRD v0.18](../PRD.md) 同步需求基準。本文尚非可直接開發的完整技術契約；正式 API、欄位格式、身分與部署介面須由相關窗口核准。此附件仍為第一優先交付文件。

## 1. 有效入口點擊（P1-TOOL-004、P1-OBS-001～002）

- AI 與非 AI 工具均由 WorkHub 後端於權限及入口狀態檢查通過後記錄使用者、工具、時間與部門。
- 後續工具未開啟或未完成工作仍保留點擊；不要求一般工具回報 started／completed／failed，不顯示啟動成功、失敗、未確認或工作完成狀態。
- 權限或停用、維護、失效入口阻擋另留事件，不計有效點擊；同次重送不可重複計數。
- 書籤、直接 URL 等外部入口不產生 WorkHub 點擊，且不納入入口點擊分析。
- 事件唯一識別、去重機制、格式、錯誤碼、版本與儲存介面待技術設計核准，不以工具 run_id 推定已完成工作。

## 2. LLM Proxy（P1-LLM-001～007）

使用 LLM 的工具後端統一經新建 LLM Proxy，憑證集中管理；逐工具設定核准模型、地端／雲端路由、版本及配額，相容模型切換不修改工具程式。非 LLM 工具不適用模型設定。

Proxy 另記錄工具、模型、Token、路由、回應時間、結果與錯誤，並以執行識別碼追溯；模型紀錄與入口點擊分開統計，不以模型成功推定工具完成。模型逾時、重試、故障切換及超額仍遵守管理者核准模型範圍。

資料可否上雲由客戶判斷並設定工具模型範圍；平台不自動辨識 Prompt／附件敏感性。全文保存與存取依 TBD-DATA-001；主管分析不得回傳未授權全文。AI 識圖維持地端 RTX 5090。

## 3. 分析與資料政策（P1-OBS-003～006）

依期間、部門、使用者、工具及授權範圍統計入口點擊；AI 模型呼叫與 Token 另行彙總。節省時間與業務效益依客戶核准基準、資料來源與公式；缺資料顯示「尚無資料」，不以點擊推算實際工作量或節省時間。不提供一般工具完成率。

留存、刪除、加密、備份與稽核依 TBD-DATA-001／TBD-NFR-001。測試資料與正式分析須區分。
