# Phase 1 UAT 與需求追蹤

> **2026-09-11 識圖交接範圍更新（以此為準）**：依使用者本次確認，AI 識圖改為未完成版本的獨立前端原始碼交接；本次不部署、不上傳 GitHub、不串接 5090，也不完成剩餘功能。WorkHub 移除內嵌識圖介面，只保留工具資訊、入口可見性與可選 URL；未設定 URL 時顯示「待設定入口」。後續辨識、後端保存、登入／權限、GPU 驗證、部署與正式 UAT 由客戶接手。现有前端部門篩選不代表已完成 AD／後端權限。本文下方涉及舊識圖建置承諾、5090 驗收或完整識圖 UAT 的敘述保留作歷史／後續需求，不屬於本次交付完成條件。範例逐筆確認與舊「整體確認」不同，交接保留目前行為，未替客戶決定正式流程。

## 1. UAT 通過規則

- 每個正式需求 ID 必須對應測試證據或經核准的不適用理由。
- 越權、敏感資料未授權上雲、AI 原始值被覆寫、未確認即可匯出為阻斷缺陷。
- 其他缺陷分級、允許未關閉數量及驗收緩衝期由 `TBD-UAT-001` 決定。
- Demo 畫面或口頭展示不能取代正式環境證據。

## 4. 證據要求

- 測試帳號、角色及 AD 群組快照。
- API／事件紀錄與對應畫面。
- 核准工具清單、部門、URL、Owner、登入方式、使用角色及 LLM 分類證據。
- 每項核准上線工具的使用數據記錄覆蓋檢查，以及主管分析數值與原始事件抽查結果。
- Proxy 路由及政策結果。
- 儀表板數值與原始資料抽查。
- AI 識圖標準答案、地端 5090 硬體與模型版本、推論設定、原始輸出、成功率報告、人工最終值及匯出檔。
- 品保人工校對基準、同類圖面抽樣資料、AI 輔助校對時間紀錄、有效問卷及滿意度計算結果。
- 缺陷清單、修正版本及複測結果。
- UAT 簽核人、日期與範圍。
