# Phase 1 工具與權限盤點

## 工具盤點表

本表依 `UMT小工具功能分類整理表.md` 保存現有工具盤點，供選擇 1–2 個試點及客戶後續上架使用，不是平台允許清單或本次逐項代上架承諾。符合平台接入規範的其他工具亦可上架。

試點需完成容器、SSO、Gateway／事件等必要接入，保留原業務功能。技術移轉後由客戶 AI 團隊自行上架其他工具。AI 識圖與 OpenWebUI 既有專項要求依 PRD；是否作為試點見 TBD-PILOT-001。

下列 LLM 分類為盤點當下現況，不限制後續路由；使用 LLM 的工具可由後台切換相容且符合資料政策的核准地端／雲端模型。AI 識圖仍依核准規格使用地端 5090。

## 角色權限矩陣

`A`＝可使用，`V`＝可查看彙總，`M`＝可管理，`-`＝不可使用。正式結果以 AD 群組對應為準。

| 功能 | 一般使用者 | 品檢員 | 主管 | IT／平台管理員 | 資安／稽核 |
|---|---:|---:|---:|---:|---:|
| 查看獲授權工具 | A | A | A | M | - |
| 啟動獲授權工具 | A | A | A | A | - |
| AI 識圖上傳／修正／確認 | - | A | - | 測試／支援 | - |
| AI 識圖匯出 | - | A | - | 測試／支援 | - |
| 主管儀表板 | - | - | V | M | 依授權 V |
| 工具目錄與權限設定 | - | - | - | M | - |
| 稽核紀錄 | - | - | 僅彙總 | 依職責 | V |
| Prompt／附件／回應全文 | - | - | - | 依政策 | 依政策 |

## 待確認清單

- AD／SSO 協定、Tenant／Domain、Claim 與群組同步頻率。
- 一人多部門、代理主管、調職、留停及離職規則。
- 主管查看範圍是直屬部門、管理階層或指定群組。
- IT 與資安是否使用不同管理角色。
- 工具端採共用 SSO、一次性 Token 或既有登入的方式。
- 優先收齊選定試點的正式／測試 URL、Owner、健康檢查、維護窗口、支援窗口及停用方式；其餘由客戶上架前補齊。
- 採購報價彙整的 AI 元件是否實際使用 LLM，以及是否須套用 LLM Proxy 規則。
- OpenWebUI 與 CNC 排程使用的雲端模型、資料分級、核准端點及 Proxy 路徑。
- CNC 作業指導書翻譯、地端 n8n 平台及 AI 識圖的地端模型、推論端點與維運責任。
- 地端 n8n 平台中哪些工作流納入 WorkHub、哪些工作流實際使用 LLM。
