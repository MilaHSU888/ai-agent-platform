# **企業資訊系統與 AI 功能分類整理表**

依 LLM 技術屬性（確定 / 可能 / 非 LLM）與部門進行分類總覽

## **整合平台內部功能**

| 功能項目 | 負責 / 使用部門 | 技術屬性 | 說明與架構細節   |
| :---- | :---- | :---- | :---- |
| **OpenWebUI (UMT AI 助理指令)** | 跨部門 / 通用 | **雲端 LLM** | 整合 AI 助理指令，並已包含「**CNC 維修經驗查詢**」知識庫對話功能。 |
| **採購報價彙整** | 採購部 | **可能用到 LLM** | 第三層 AI 算力應用，運行於地端 RTX 5090 機台。 架構：OCR → Python → **AI (RTX 5090\)**。 |
| **CNC 作業指導書翻譯** | 製造二部 | **Local LLM** | 利用 LLM 進行標準作業指導書 (SOP) 多語系自動化翻譯。 |
| **AI 識圖大師** | 製造二部 | **Local LLM** | 多模態 AI 圖面 / 影像辨識與智能分析。 |
| **地端 n8n 平台** | 總務部 | **Local LLM** | 地端私有化部署之自動化工作流整合平台。 |
| **CNC 排程** | 製造二部 | **雲端 LLM** | 機台生產排程、產線資源規劃與調度系統。 |
| **製造一部派工查詢** | 製造一部 | **非 LLM** | 現場派工紀錄與生產狀態即時查詢小工具。 |
