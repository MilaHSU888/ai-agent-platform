# AI 識圖獨立交接 · 2026-09-11

識圖實作、範例圖面、球標資料與 Excel 匯出已移至獨立專案 `ai-vision-tool`，本平台不再內嵌。

- 工具仍歸屬製造二部，保留原部門篩選行為；這不是 AD／後端權限驗證。
- 在 `app/page.tsx` 的 `vision` 工具登錄中設定 `url`；目前空字串顯示「待設定入口」。
- URL 必須為完整 HTTP(S) 位址；設定後以 `noopener noreferrer` 新分頁開啟。無網址時不會回退到其他示範工作區。
- 後續網站的登入、API 權限、模型、資料保存及部署由客戶處理；平台不傳遞金鑰或假設 URL 直連具備身分驗證。
- 交接範例維持兩頁 39 球標／48 筆規格，逐筆確認後填回客戶原表；內容為客戶參考答案，非模型輸出。
- 目前只製作本機交接包；未發布網站，未上傳 GitHub。舊離線產物需重新執行 `pnpm build:offline` 才會反映移除。
