# AI Agent Platform：企業智慧工具平台

此平台是提供約 300–350 位員工使用的企業工具整合入口，對應目前的 Phase 1 實作。平台依全公司及各部門分類工具，並提供管理者使用率與效益統計。

## 部門分類

- 全公司共用
- 財務部、資訊部、人力資源部、總務部
- 研發部、採購部、業務部、資材部
- 製造一部、製造二部、經營管理室

## 主要功能

### WorkHub 工具中心

- 依部門及 AI／非 AI 類型篩選工具
- 工具名稱與用途搜尋
- 顯示使用人數、執行次數及預估節省工時
- 進入工具前顯示使用成效
- 響應式桌面與手機版面

### 管理者儀表板

- 活躍使用者與整體採用率
- 工具執行次數與預估節省工時
- 部門使用排名與工具成效明細
- 本月、近三個月及本年度期間切換

### AI 識圖大師

- 使用客戶提供的真實球標辨識報告案例
- 球標 1、13、2、3、4、5、6、7 逐筆核對
- 中央圖面與右側辨識結果同步定位
- 選取項目時框選正確的圖面位置
- 人工確認、修改、標記問題與進度追蹤
- 鍵盤快速核對及完成後匯出流程

### 採購報價匯整工具

- 採購案編號必填驗證
- 數量區間設定
- 多格式、多檔案拖放上傳
- 檔案清單、單筆移除與清空重來
- 比較表匯出狀態、使用說明及歷史查價

### 企業／部門知識庫

- 全公司及每個部門皆有知識庫問答入口
- 自動附加「全公司＋目前部門」知識庫
- 顯示引用來源與原始文件入口
- 部門專屬建議問題與對話紀錄
- 部門管理員可新增知識庫、上傳文件及啟用／暫停來源
- 全公司必備來源由平台管理員控管

### Prompt 範本

- 個人、部門共用及全公司共用 Prompt
- Prompt 搜尋、一鍵套用與瀏覽器端保存
- 輸入 `/` 顯示可用 Prompt
- 輸入前幾個字即時縮小範圍
- 支援方向鍵、Enter、Tab 與 Esc 操作

## 本機執行

### 系統需求

- Node.js `>=22.13.0`
- pnpm

### 安裝與啟動

```bash
pnpm install
pnpm dev -- --port 3002
```

開啟 [http://localhost:3002](http://localhost:3002)。

### 建置驗證

```bash
pnpm build
```

| `app/page.tsx` | 平台、儀表板及各工具主要互動 |

## Phase 1 範圍說明

目前 OpenWebUI 問答、Prompt 與知識庫管理為前端整合展示。正式串接需要提供：

- OpenWebUI URL 與 API Token
- 使用模型 ID
- 全公司與各部門 Knowledge Base ID
- AD 群組與 OpenWebUI 權限對應
- Prompt 與知識庫管理 API 權限

正式上線時，使用紀錄應只保存必要的遙測與成效資料，不應讓主管查看員工的完整提問內容。
